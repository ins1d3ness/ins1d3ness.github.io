# Welcome to my digital garden!

These are my notes, thoughts, experiments, and explorations. This space was built from several archives: my Metaroa blog, my first alt blog, *corpses in acid rain*, and my main Substack hub, *Acid Diaries* (which, at one point, used to be my main digital garden (2022–2026)).

As of November 11th, 2026, only *The Emporium* (Metaroa blog) archive has been loaded, with the *Acid Diaries* and *CIAR* archives still TBT. I'll be undertaking a full-scale migration over the coming weeks.

If you'd like to support this project, or my work more broadly, you can do so [here](https://ko-fi.com/slijepcevic).

If you'd like to support FAUST, FAUST Books and our other work, you can do so [here](https://ko-fi.com/faustcollective).

I'll be using this as a sort of bulletin board for updates + maintenance things and other news, so keep an eye out for future entries! <3 

The best way to reach me these days is via email, slijepcevic.ivan@proton.me. 

If you'd like to join the [[faust-mailing-list]]  you can! The idea is to have that as a space for sharing blurbs, ideas, news, updates, event details etc. If you'd like to stay in touch with what we do and perhaps get involved, right now, this is the best way to do it. You can also check out [*FAUST Resource*](https://faustresource.substack.com/), the main digi hub for FAUST work and news.

Anyway, TTYS. This is how things look like as of now.
